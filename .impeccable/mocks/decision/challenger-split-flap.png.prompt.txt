Use case: ui-mockup
Asset type: full-fidelity 16:10 desktop web dashboard decision comp
Primary request: Create a shippable, high-fidelity desktop UI mockup for EventPass, an event operations dashboard for administrators, in the visual direction “Concourse Board.”
Scene/backdrop: A straight-on desktop application viewport, 16:10 landscape, filling the image edge to edge. This is the interface itself, not a laptop, monitor, room, or perspective product shot.
Subject: A structured event operations dashboard with a narrow top utility bar, a restrained left navigation rail, and one dominant time-ranked operations board. Multiple event rows are ordered by time. The row for “Fall Community Gala” is expanded in place to reveal arrivals/check-ins, email delivery, and immediate actions.
Style/medium: Highly polished production web UI. Visual language derived from a rail concourse split-flap departures board: matte black flap faces, off-white condensed uppercase typography in fixed rectangular cells, crisp brushed-steel horizontal and vertical rules, tiny amber row lamps, and dim red exception indicators. Dense but calm, operational, precise, and highly legible; clean and simple despite the dark grid. The split-flap idea must organize the information architecture, not become theatrical decoration.
Composition/framing: 16:10 desktop canvas. Top bar shows the EventPass wordmark at left and compact administrator utility controls at right. Left rail uses concise navigation. Main area has a clear title and a single large board with column headers for time, event, venue, arrivals, delivery, and status. Show at least five ranked rows. The expanded “Fall Community Gala” row occupies roughly the middle third and reveals a tidy subordinate detail grid plus a compact action strip. Strong hierarchy, generous outer margins, tight internal alignment, clear selected/expanded state, and believable browser-scale controls.
Lighting/mood: Even, flat interface rendering with excellent contrast. No atmospheric lighting, glow, cinematic haze, reflections, or dramatic shadows.
Color palette: Near-black and charcoal flap faces; warm off-white text; cool brushed-steel rules; restrained amber lamps; dim muted red only for exceptions. No gradients.
Materials/textures: Very subtle matte panel texture and restrained brushed steel, both understated enough to preserve text clarity.
